# فهرست عکس‌ها

همه‌ی عکس‌ها را سازنده تهیه کرده است. فرمت webp، عرض ۱۲۰۰ پیکسل، نسبت ۳ به ۲.

| دستور | فایل |
|---|---|
| کیک شکلاتی | images/chocolate-cake.webp |
| کیک ردولوت | images/red-velvet.webp |
| کیک هویج و گردو | images/carrot-walnut-cake.webp |
| کیک پای سیب | images/apple-pie.webp |
| کیک تیرامیسو | images/tiramisu-cake.webp |
| شیرینی نخودی | images/chickpea-cookie.webp |
| شیرینی کشمشی | images/raisin-cookie.webp |
| شیرینی دانمارکی | images/danish-pastry.webp |
| شیرینی نارگیلی | images/coconut-cookie.webp |
| شیرینی خرمایی | images/date-cookie.webp |

برای جایگزین کردن یک عکس، فایل جدید را با همان نام بگذار و در service-worker.js عدد CACHE_VERSION را بالا ببر.
