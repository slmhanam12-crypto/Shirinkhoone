# شیرینی‌خونه

اپ فارسی دستور پخت کیک و شیرینی. یک PWA ساده و بدون سرور که روی گوشی نصب می‌شود و بدون اینترنت هم کار می‌کند.

سازنده: هانیه سلمانی

---

## ۱) پوشه‌ها

| مسیر | چیست |
|---|---|
| `index.html` | صفحه‌ی اصلی اپ (هدر، محتوا، نوار پایین) |
| `style.css` | ظاهر اپ. رنگ‌ها در بخش `:root` بالای فایل هستند |
| `app.js` | منطق اپ (صفحه‌ها، جستجو، علاقه‌مندی‌ها، محاسبه‌ی مواد، پیشنهاد دستور) |
| `manifest.json` | مشخصات نصب اپ (نام، رنگ، آیکون) |
| `service-worker.js` | کار کردن آفلاین و به‌روزرسانی |
| `data/` | محتوای اپ: دستورها، مواد، دسته‌ها و متن «درباره من» |
| `fonts/` | فونت وزیر (Medium و Bold) |
| `icons/` | آیکون اپ |
| `images/` | عکس ۱۰ دستور |
| `images/kitchen/` | عکس‌های بخش «بهم بگو چی تو آشپزخونه داری؟» (۵ فایل webp) |
| `design/` | سند طراحی، رنگ‌ها و فهرست عکس‌ها (فقط برای مرجع) |

---

## ۲) اجرا و تست روی کامپیوتر

فایل `index.html` را با دابل‌کلیک باز نکن؛ Service Worker و فایل‌های داده فقط از طریق یک آدرس وب کار می‌کنند. در پوشه‌ی پروژه این دستور را بزن:

```
python3 -m http.server 8000
```

بعد در مرورگر برو به `http://localhost:8000`.

برای تست آفلاین: یک بار اپ را باز کن، بعد در ابزار توسعه‌دهنده‌ی Chrome (F12) از بخش Network گزینه‌ی Offline را بزن و صفحه را دوباره بارگذاری کن.

---

## ۳) انتشار روی اینترنت (لازم برای نصب روی گوشی)

PWA برای نصب روی گوشی باید روی آدرس **HTTPS** باشد. ساده‌ترین راه‌ها (رایگان):

- **Netlify Drop:** سایت `app.netlify.com/drop` را باز کن و کل پوشه‌ی پروژه (نه فایل ZIP) را بکش داخلش.
- **GitHub Pages:** پروژه را در یک مخزن (repository) بگذار و Pages را از تنظیمات روشن کن.

بعد از انتشار، آدرس را در Chrome گوشی باز کن و از منوی مرورگر «Install app» یا «افزودن به صفحه‌ی اصلی» را بزن.

---

## ۴) ساخت APK برای اندروید

من در ساخت پروژه فایل APK نساخته‌ام. با PWABuilder خودت می‌توانی بسازی:

1. اپ را مثل بخش بالا روی یک آدرس HTTPS منتشر کن.
2. برو به `pwabuilder.com` و آدرس اپ را بزن.
3. اگر امتیاز و ایرادها را نشان داد، بررسی کن.
4. گزینه‌ی **Package for stores** و بعد **Android** را انتخاب کن.
5. فایل را دانلود کن. داخل ZIP یک APK (برای نصب مستقیم) و یک AAB (برای گوگل‌پلی) و فایل کلید (keystore) هست.
6. **فایل keystore و رمزش را حتماً جای امن نگه دار.** بدون آن نمی‌توانی نسخه‌ی بعدی اپ را برای همان کاربران به‌روز کنی.

## ۵) عوض کردن محتوا

### متن «درباره من» و آیدی‌ها
فایل `data/app-info.json` را باز کن. دو فیلد `telegram` و `instagram` الان **خالی‌اند**. آیدی‌ات را بدون `@` بنویس، مثلاً:

```json
"telegram": "your_id",
"instagram": "your_id"
```

هر کدام را که پر کنی، یک دکمه در صفحه‌ی «درباره من» ظاهر می‌شود.

### اضافه کردن یک دستور
1. عکسش را (ترجیحاً webp، نسبت ۳ به ۲، عرض ۱۲۰۰ پیکسل) در `images/` بگذار.
2. اگر ماده‌ی جدیدی دارد، آن را در `data/ingredients.json` اضافه کن (با یک `id` یکتا).
3. دستور را در `data/recipes.json` اضافه کن. نمونه:

```json
{
  "id": "cake-example",
  "category": "cakes",
  "title": "کیک نمونه",
  "image": "images/example.webp",
  "summary": "یک جمله‌ی کوتاه",
  "difficulty": "آسان",
  "prepMinutes": 20,
  "cookMinutes": 35,
  "extraTime": "",
  "baseServings": 8,
  "yield": { "amount": 8, "unit": "برش" },
  "ingredients": [
    { "ingredientId": "flour", "amount": 200, "unit": "گرم" },
    { "ingredientId": "walnut", "amount": 50, "unit": "گرم", "optional": true }
  ],
  "steps": ["مرحله‌ی اول", "مرحله‌ی دوم"],
  "secrets": ["یک نکته"]
}
```

4. نام عکس را در لیست `FILES` فایل `service-worker.js` هم اضافه کن.
5. عدد `CACHE_VERSION` را بالا ببر (بخش ۶).

**نکته‌ها:**
- `category` یا `cakes` است یا `sweets`.
- `id` هر دستور و هر ماده بعد از انتشار **نباید عوض شود**؛ علاقه‌مندی‌های کاربرها با همین `id` ذخیره شده است.
- مقدار مواد (`amount`) همیشه برای `baseServings` نوشته می‌شود. اپ بقیه را خودکار حساب می‌کند.
- ماده‌ای که با `"optional": true` علامت بخورد، جلوی پیشنهاد دستور را نمی‌گیرد.
- هر ماده می‌تواند `group` (مثلاً «مواد روکش») و `note` (مثلاً «رنده‌شده») داشته باشد.
- نام مواد فقط یک‌جا، در `ingredients.json` نوشته می‌شود و همه‌ی دستورها فقط `id` را می‌آورند.

### صفحه‌ی «بهم بگو چی تو آشپزخونه داری؟»
پنج عکس آشپزخانه با لمس باز و بسته می‌شوند و مواد همان بخش را نشان می‌دهند. عکس‌ها در `images/kitchen/` هستند (webp، عرض ۸۰۰ پیکسل):

| بخش | نام فایل |
|---|---|
| یخچال | `fridge.webp` |
| قفسه‌ی آرد و پودرها | `flour-shelf.webp` |
| کابینت آجیل و خشکبار | `nuts-cabinet.webp` |
| کشوی ادویه و طعم‌دهنده‌ها | `spice-drawer.webp` |
| سبد میوه و بقیه | `fruit-basket.webp` |

دسته‌بندی مواد هر بخش (و مسیر عکسش) در `data/kitchen.json` است. بدون دست زدن به کد می‌توانی ماده‌ها را بین بخش‌ها جابه‌جا کنی (هر ماده فقط در یک بخش باشد و `id` ها عوض نشوند). برای عوض کردن یک عکس، فایل جدید را با همان نام بگذار و `CACHE_VERSION` را بالا ببر.

### عوض کردن عکس‌ها
فایل جدید را با **همان نام** جایگزین کن (مثلاً `images/chocolate-cake.webp`) و بعد `CACHE_VERSION` را بالا ببر.

## ۶) به‌روزرسانی اپ

هر بار هر فایلی را عوض کردی (کد، عکس، فونت، آیکون، دستور)، در `service-worker.js` عدد `CACHE_VERSION` را بالا ببر، مثلاً از `v1` به `v2`. بعد دوباره منتشر کن. کاربران با اینترنت، یک نوار «نسخه‌ی جدید آماده است» می‌بینند و با زدن «به‌روزرسانی» نسخه‌ی جدید نصب می‌شود.

اگر فقط محتوای پوشه‌ی `data/` را عوض کنی، اپ آن را معمولاً با اینترنت خودش می‌گیرد، ولی بالا بردن نسخه راه مطمئن‌تری است.

---

## ۷) فونت

الان دو وزن از فونت **وزیر** داخل پروژه است: Medium (۵۰۰) برای متن و دکمه‌ها و Bold (۷۰۰) برای تیترها. فایل وزن Regular (۴۰۰) نداشتیم و متن‌ها کمی پررنگ‌تر از حالت عادی دیده می‌شوند.

اگر بعداً فایل Regular را پیدا کردی:
1. آن را در `fonts/` با نام `Vazir-Regular.ttf` بگذار.
2. در `style.css` زیر دو خط `@font-face` موجود، این خط را اضافه کن:
   `@font-face { font-family: "Vazir"; src: url("./fonts/Vazir-Regular.ttf") format("truetype"); font-weight: 400; font-display: swap; }`
3. در همان فایل، در `body` مقدار `font-weight: 500` را به `400` تغییر بده.
4. نام فایل را به لیست `FILES` در `service-worker.js` اضافه کن و `CACHE_VERSION` را بالا ببر.

مجوز فونت وزیر آزاد (SIL OFL) است.

## ۸) نکته‌های مهم

- **آیکون:** آیکون اپ یک عکس PNG است (`icons/`)، نه SVG. سه نسخه دارد: ۵۱۲، ۱۹۲ و maskable (برای برش‌های گرد اندروید).
- **علاقه‌مندی‌ها:** فقط روی همان گوشی ذخیره می‌شوند. اگر کاربر داده‌های مرورگر یا اپ را پاک کند، از بین می‌روند.
- **دستورها را امتحان کن:** مقدارها بر پایه‌ی دستورهای رایج نوشته شده‌اند، ولی قبل از انتشار هر دستور را یک بار در آشپزخانه‌ی خودت بپز، مخصوصاً دانمارکی و خرمایی را که مخمری‌اند.
- **پیشنهاد دستور:** بر اساس مواد اصلی هر دستور کار می‌کند و نمک و مواد اختیاری را حساب نمی‌کند. اگر دستوری تا ۳ ماده کم داشته باشد، در «نزدیک‌ترین‌ها» نشان داده می‌شود.
- **لینک تلگرام و اینستاگرام** فقط با اینترنت باز می‌شوند؛ بقیه‌ی اپ آفلاین هم کار می‌کند.
